# DocConnect
Website created to cut spend time and simplify communication for patient with a doctor
To start the website, run in the root directory:

1. Navigate to the `client` directory:
   ```bash
    cd client
2. Run the project:
    ```bash
    npm run dev
If any issues arise with missing files (which is likely), install the tools listed below and then run dev again.

💻 Technologies Used
The React project, CURRENTLY, uses the following tools and libraries:

npm - package manager

react-dom - for rendering React components

vite - build tool for fast development

mui - Material UI for styling and components

express - for creating the backend server

pg - library for connecting to PostgreSQL

sequelize - ORM for working with the database

nodemon - for automatic server restarts on code changes
